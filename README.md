# Lシンク インタビュー｜挿入図

Lシンク（LINE公式アカウント向けAI営業支援）のインタビュー収録で、
各ブロックの途中に表示する図。全6枚を1ページにまとめています。

公開ページ: https://writeup-inc.github.io/lsync-interview-figures/

## 中身

| # | 出すタイミング | 図の主題 |
|---|---|---|
| 1 | ブロック① 0:00–3:00 | はじめの一手が、いつも人だった |
| 2 | ブロック② 3:00–7:00 | タグを、人がつけない |
| 3 | ブロック② 3:00–7:00 | 順番を逆にすると、票が逃げる |
| 4 | ブロック③ 7:00–9:00 | 登録しても、9割は黙っている |
| 5 | ブロック④ 9:00–11:00 | 設定画面と格闘する時間をなくす |
| 6 | ブロック④ 締め | 5分だけ雑談して、ついたタグを見る |

## 使い方

- 左右キー / スペース、画面下のボタン、スマホはスワイプで送る
- `#1`〜`#6` を URL の末尾に付けると、その図を直接開ける
  （例: `.../lsync-interview-figures/#3`）
- 「表示切替」でライト／ダークを切り替え。収録の背景に合わせて選ぶ

単一HTML・外部依存なし。`index.html` をそのまま開いても動きます。
